# Root & Remedy — Medicinal Garden Kit Affiliate Landing Page

A responsive React + Vite landing page designed for GitHub and Vercel deployment.

## Included
- Premium botanical design with responsive layout
- Smooth anchor navigation, hover effects, reveal animations, FAQ accordion
- Mobile navigation
- Affiliate buttons linked to: https://medicinalseedkit.com/kit/#aff=habeeb63
- Affiliate disclosure and medical-information disclaimer
- Stock photos loaded from Unsplash and fonts from Google Fonts

## Run locally
1. Install Node.js (LTS).
2. Extract this ZIP.
3. Open a terminal in this folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL shown in your terminal.

## Deploy to GitHub + Vercel
1. Create a new GitHub repository.
2. Upload the extracted project files (keep the `src` folder and `package.json`).
3. In Vercel, choose **Add New → Project**, import the repository.
4. Framework preset: **Vite** (usually detected automatically).
5. Build command: `npm run build`
6. Output directory: `dist`
7. Click **Deploy**.

## Customize
- Edit page text and sections in `src/main.jsx`.
- Change colors, spacing, fonts, and effects in `src/styles.css`.
- The affiliate URL is set near the top of `src/main.jsx` as `AFFILIATE_URL`.
- Replace the illustrative Unsplash image URLs with images you have permission to use.
- Review all product details, pricing, and claims before publishing. The page intentionally avoids guaranteeing health outcomes.
